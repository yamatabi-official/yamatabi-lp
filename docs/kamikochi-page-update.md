# 上高地ページ：鑑賞から、自分の滞在へ（2026-10-19）

## 構成と実装
- `experience.html` のみを紹介ページとして改修。トップのキービジュアル・他作品は変更していない。
- ドラマ中心のファーストビュー → 3つの縦カードで追体験 → 1案の写真付きタイムライン・模式図 → 4分類の必要条件 → 最後の主ボタン、という順序。
- ナビは「過ごし方／一日の流れ／行く準備」の3つ。鑑賞・カード操作を必須にしない。従来の準備アンカー `#access` / `#season` / `#before-you-go`、タイムライン `#walk`、概念マップ `#story-map`、共有URLの `day` を残す。`#your-day` は最後の計画導線。
- 最初の動画自動再生オーバーレイは、今回のユーザー指定「操作でドラマを開始」に従い、紹介ページから `river-intro.js` の読み込みを外した。素材・元スクリプトは保持。
- 最初の「ドラマを観る」は写真の位置で直接インライン再生（1回の操作・初期無音）。モーダルや確認画面を挟まない。スマートフォンは再生中に文字を下へ移し、映像をトリミングせずnative controlsで再生する。音・説明字幕・閉じるを追加。終幕後に任意の余韻導線を表示。
- 既存の `quiet-time.js` / `quiet-time.css` による余韻・再鑑賞、保存、音選択、説明字幕、終了・停止は継続。通常のページ内プレーヤーも折りたたみで残し、JSなしの代替にする。
- カードはnative details。写真は静止、梓川の動画は明示的な再生操作でのみsrcを付ける。閉じる・画面外・ページ非表示で停止。余韻モーダルを開くとページ内映像を止める。背景タブから勝手に再開しない。
- 模式図は縮尺・方角を持たない。スマートフォンは読める大きさの縦経路、PCはSVG。実際の移動には公式園路マップを案内。旧概念マップは補足のdetails内へ移動して機能を残す。
- 新規 `kamikochi-page.css` / `kamikochi-page.js`。既存CSSは維持し、上高地ページのクラスに限定して上書き。

## 計画画面
- `kamikochi-plan.html` / `.css` / `.js` は同一ブランドサイト内の計画専用画面。個人プロフィール・準備進捗を紹介ページに詰め込まない。
- 出発地（最大80文字・詳しい住所不要）、任意の日程、同行者、交通手段、準備チェックを入力。明示的な保存でlocalStorage `yamatabi-kamikochi-plan-v1` へ記録。
- 利用者の入力を外部APIへ送らない。共有リンクには出発地・日程・チェックを含めない。テキストのダウンロードには本人の入力を含める。
- 保存拒否時は未保存と表示し、入力結果とテキスト保存を利用可能にする。再訪の読込・編集・削除、Web Share / クリップボード / 手動コピーを用意。予約・決済・自動経路検索・時刻照会は未実装。
- 旧 `yamatabi-kamikochi-day-v1` の同行者とチェックを初期値として引き継ぐ。新計画の保存成功後は旧キーを削除する。旧 `journey.js` は履歴として保持するが紹介ページでは読み込まない。
- `?day=together` などの旧共有パラメータは紹介→計画の導線へ引き継ぐ。
