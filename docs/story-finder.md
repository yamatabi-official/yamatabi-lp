# 気分と体験から物語を探す

トップページのSTORIES内に配置。外部AI・APIキー・DB・利用料は不要。
選択内容は保存・外部送信せず、ブラウザ内で掲載作品のタグと照合する。
自由入力のチャット機能ではなく、気分1つ＋体験1つの選択式。

## 作品データ
works.json の既存の作品項目に recommendation を追加する。

```json
"recommendation": {
  "moods": ["calm", "romance"],
  "experiences": ["riverside", "scenery"],
  "experienceTip": "作品の舞台での過ごし方のヒント",
  "experienceUrl": "experience.html#walk"
}
```

気分：calm（ひと息）、romance（ときめき）、inspired（刺激）、adventure（冒険）。
体験：riverside（川辺の散策）、scenery（山の景色）、summit（山頂）、camping（キャンプ）。
作品と公開済みの案内で裏付けられるタグだけを付ける。未知の場所・旅程を生成しない。
URLは同一サイトの実在するページに限定する。タグ項目がない作品を、一致作品とみなさない。

## 選定
気分の一致・体験の一致に各1点。最高点の作品を最大3件表示し、同点は掲載順。
- 2点：両方に合うと表示し、理由と体験案内へのリンクを提示。
- 1点：一部だけ合うと表示し、一致しない条件も明記。
- 0点：合う作品がないことを明記し、公開中の作品を代わりに紹介。推薦と偽らない。
- 0作品：公開作品がまだないと表示。

現在の上高地作品はcalm / romance、riverside / scenery。
山頂・キャンプの体験として案内しない。実際に登山や旅行の予約が成立する機能ではない。

## 確認した動作
320 / 390 / 1280pxでの選択、必須入力、一致・一部一致・一致なし、再選択、結果へのフォーカス、作品・散策リンク、横はみ出しなし。
カタログ取得失敗後の再試行、追加作品を用いた順位検証（テスト用データのみ）、JavaScript無効時の作品一覧への導線。
