# 物語から、日常の余韻へ

## 組み込み位置
- トップの既存作品一覧の下に、上高地ページの `#quiet-time` への導線。
- 上高地ページの作品リンク／余韻カードから、同一ページのネイティブ `dialog` を開く。
- 2026-10-19の紹介ページ再構成で、最初の主ボタンはドラマ、直後は3カードの追体験へ変更。余韻モーダルは作品ボタン・川カードから引き続き使える。計画は紹介の最後から専用画面へ。
- 既存の通常プレーヤー・作品・マップ・休日プラン・パートナーは残す。通常プレーヤーの終幕には任意の「川辺の余韻へ」を表示。
- `quiet-time.js` / `quiet-time.css` が体験を担当。新規サイト・フレームワーク・外部APIは使わない。

## 状態と操作
1. 入口：作品の音を本人が選択。標準は無音。物語から／余韻から選べる。
2. 鑑賞：既存21.3秒動画。ネイティブコントロール（音量・シーク・再生停止）に加え、説明字幕・ミュート切替・停止・閉じるを用意。
3. 終幕：`ended` から同一画面の梓川背景へ約1.2秒でフェード。約1.7秒の間のあと飲み物への誘いを表示。何もしなくても川辺で過ごせる。
4. 余韻：梓川の無音ループ／空の静止写真を選択。「この時間を過ごす」で画面外への誘い、「このまま眺める」「表示を隠す」で表示を減らす。停止・再生・閉じる・表示を戻すは常に操作可能。時間制限・達成率・感想要求はない。
5. 保存：明示的な「手元に残す」でlocalStorage `yamatabi-quiet-time-v1` にバージョンと風景（river/sky）のみ記録。ログイン・通信・個人情報なし。保存後の風景変更も同じ保存先へ記録。保存不可の場合は理由とブックマーク案内を表示。
6. 再訪：同じページのカードに保存済みを表示し、再視聴／余韻へ戻れる。保存はブラウザ単位で、InstagramからSafariなどへの移動や端末変更では引き継がれない。

## 素材監査・不足
- `kamikochi-film.mp4`：既存『秋の上高地』、512×910、約21.3秒、元の音声トラックあり。人物・川辺・振り返る場面と画面内テキストをサンプル確認。AI生成／実写の混在ブランドであり、この映画を実写の撮影記録とは記載しない。
- **カップを持って飲む場面は確認できない。** この試作は既存作品のあとに鑑賞者への誘いをつなぐ。飲む場面が物語内にあると説明しない。必要なら許諾済みの対応シーンを作品として編集し、上映時間や字幕も合わせて差し替える。
- `assets/kamikochi-river-intro.mp4`：提供済み梓川動画から作成した無音・全編版。既存ファイルを再利用し、新規の架空の散歩映像は用意しない。川辺の風景をループで見せる。カメラを「座る」位置へ移動する素材はないため操作名は「川辺を眺める」。縦素材のためPCは拡大・トリミングで解像感に限界あり。
- `assets/about-journey.webp`：ユーザー提供 `IMG_8879.JPG` の空の写真。上高地で撮影したとは断定しない。「空の写真・音声なし」と表示する。静止写真の切替に実際の反応がある。
- 元動画に音声トラックはあるが、川音としての内容・収録品質・利用条件は未確認。**余韻には環境音を使用しない**。「音声なし」と表示。環境音が録音されているように見せかけない。確認済みの川音が届いたら、独立音声として本人の開始操作・音量・停止とともに追加する。映画の音はオリジナルの音声を本人が選んだときのみ再生する。
- `assets/captions/kamikochi-scenes-ja.vtt`：確認できた画面内テキストと情景の説明字幕。**会話・音楽・効果音の完全な字幕ではない**。入口にも「画面の文字と情景の説明」と表記。会話音声の全文確認／正確な書き起こしと字幕監修は未完了。今後、確認済みの会話・音の字幕へ差し替える。現状は情景の説明字幕として表記する。

## 読み込み・アクセシビリティ
- 体験用動画のsrcは利用者が物語／余韻を選ぶまで付けない。新しい導線は `#quiet-time` なので既存のページ入場動画を挟まない。
- 音は標準ミュート。余韻への切替時に映画の音を止める。同時再生せず、閉じる／画面非表示／ページ離脱でも停止する。閉じたら動画srcを外す。背景から戻っても勝手に音を再開しない。
- 動きを減らす設定／省データでは余韻は静止画で開始。「風景を再生」を本人が選ぶと再生できる。空は常に静止画。
- 自動再生拒否・動画読込失敗でも、再生操作または写真・終了の選択を残す。
- dialog標準のモーダル・フォーカス制御、Escape、閉じた後の起点復帰。表示を隠しても常に見える安全操作（スマートフォンでは下端）を隠さない。
- JS／dialog非対応時は既存の動画プレーヤーへのアンカーと通常ページで鑑賞可能。

## ローカルプレビュー
`python3 -m http.server 8000 --bind 127.0.0.1` をリポジトリで実行。
`http://localhost:8000/experience.html#quiet-time` またはトップの「物語と余韻をひらく」から。
初回はローカル試作として実装・確認。その後、ユーザーの「公開していいよ」という承認により公開対象となった。
