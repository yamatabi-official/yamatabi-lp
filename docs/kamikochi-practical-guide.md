# 身軽に過ごす上高地：現地情報の追加（2026-10-21）

## 組み込み
既存experience.htmlの準備欄に追加。モデルコース・天気・装備・アクセス・計画保存と、作品HERO・梓川導入は維持する。新たな外部スクリプトや画像、地図サービスは追加しない。
- #season：シャツ/保温着/防風防水アウターの重ね着と、歩行/休憩/風雨の3場面。気温だけで装備の十分さを判断しない。季節別服装ガイドの記載を基に編集した一般的な通常期の提案。
- #light-packing：持参・買い足し・預けるの判断、店舗3件、ターミナル手荷物預かり。大正池スタートでは預かり所が後半にあることを明示。
- #access：新島々を鉄道の最寄りとして紹介。松本から電車約30分、新島々からバス約1時間、ターミナルから河童橋徒歩約6分/300m。公式目安で、待ち時間と接続は別。
- #rest-and-onsen：休憩3候補と入浴3候補。小梨の湯は温泉ではないと明記。料金、当日の空き、未確認の徒歩所要時間を推測で載せない。
- #before-you-go：#visit-hoursと#season-guide。帰りの最終便、施設の受付/受取時間、2026年シーズン終了日を区別。春夏秋冬の景色と支度の概要。冬季は通常散策の対象外。

- 靴・ザック・防寒着が現地で全て揃うとは約束しない。具体的商品、ブランド、サイズ、レンタル、在庫を未確認のまま案内しない。

- 一律の「閉園17時」とはしない。バス最終便・施設の最終受付・荷物受取・シーズン終了を別々に示す。
- 冬季の入山は夏道の散策と混ぜない。過去の気温平均を今年の予報として表示しない。
