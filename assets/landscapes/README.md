## 未採用理由
- IMG_2261：雲と稜線は魅力的だが、今回は夕方の山並みを優先。山の景観の役割が重なる。
- IMG_2358：ロープウェイ施設から始まるため、今回の自然中心の連続性から外れる。
- IMG_2362：山と池の景観は次回候補。3本に絞るため、水辺は川を選定。
- IMG_2460：山頂・雲海・稜線が多く、短い静かなクリップには情報量が多い。
- IMG_2657：稜線の映像は今回の夕方シーンと役割が重なる。
- IMG_2985：雪景色の印象が強く、草原と川の流れに冬季の別の旅を混在させるため保留。

## 動作
MP4のsrcは再生直前まで付与しない。ミュート・ループ・インライン再生。
風景クリップと完成作品を含め、同時再生は1本のみ。
画面外と非表示タブで停止、省データ／動きを減らす設定では手動再生。
読込失敗時はポスターを残して状況を表示。JavaScript無効時は静止画を表示。
